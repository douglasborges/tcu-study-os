# TCU Study OS no Dock — macOS

1. Atualize o GitHub Pages para a v11.
2. Abra a URL do app no Safari.
3. Confirme que o rodapé mostra **v11.0**.
4. Use **Arquivo → Adicionar ao Dock** (ou Compartilhar → Adicionar ao Dock, conforme a versão do macOS).
5. Depois, use preferencialmente o Dock como seu ambiente principal.

Se o Dock e o Safari mostrarem dados diferentes, isso é armazenamento local separado. Exporte JSON no ambiente correto e importe no ambiente que você decidiu usar.
